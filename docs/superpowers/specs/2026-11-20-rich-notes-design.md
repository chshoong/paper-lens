# Paper Lens 노트 꾸미기 (노션식 편집) 설계

작성일: 2026-11-20 · 이전 설계: `2026-11-20-study-mode-design.md`

## 1. 의도
사용자는 노션에서 하던 것처럼, 쓰는 즉시 꾸며진 모습으로 노트를 쓰고 싶어 한다. 굵게(⌘B), 밑줄, `##` 제목, 글자 크기, 글자 색, 형광펜이 필요하다. 지금 노트는 블록을 누르면 Markdown 원문 textarea가 열리고 기호가 그대로 보인다. 이 방식이 공부 흐름을 끊는다. 요청은 "사용하기 편하게 구성해줘"다.

## 2. 목표 / 비목표 / 반목표
**목표**
- 글 블록을 누르면 꾸며진 모습 그대로 편집된다(WYSIWYG).
- 굵게·기울임·밑줄·취소선, 제목 3단계, 글자 크기 3단계, 글자 색, 형광펜, 글머리·번호·체크박스 목록, 인라인 수식, 줄 단위 수식을 쓸 수 있다.
- 단축키와 Markdown식 입력이 바로 변환된다.
- 지금 기능은 그대로 유지한다: 블록 저장(db/local), Claude가 쓰는 블록, 인용·LaTeX·그림 가져오기, Markdown 내보내기, 블록 끌어서 옮기기, 수식 블록.

**비목표**
- `/` 명령 메뉴, 표 편집, 자유로운 px 글자 크기, 글꼴 바꾸기, 여러 블록에 걸친 선택과 꾸미기.

**반목표 (동작해도 실패인 경우)**
- 한글을 입력하는 중에 글자가 깨지거나 중복된다.
- 블록을 열었다 닫기만 했는데 내용이 바뀌거나 사라진다. Claude가 쓴 표나 코드가 날아가는 경우가 여기에 해당한다.
- 편집 중 모습과 다 쓴 뒤 모습이 다르다.
- 꾸밈이 저장되지 않고 새로고침하면 사라진다.

## 3. 제약
- Artifact CSP: 스크립트는 cdnjs에서만 받을 수 있고, 외부 CSS는 금지다. 그래서 Quill의 CSS는 필요한 부분만 페이지에 넣는다.
- 저장 형식은 지금처럼 블록의 `text`(문자열)다. Claude는 SKILL에 따라 Markdown으로 블록을 쓰고, 내보내기도 Markdown이다.
- 기존 테스트 75개가 지키는 **성질**은 계속 지켜야 한다: IME 안전, `$` 처리, 원격 쓰기가 편집 중인 블록을 건드리지 않음, 느린 저장 중 입력 유실 없음, 디바운스 저장, db 없음 대처. 이번에 바뀌는 동작(Enter=새 블록, textarea 편집기, 미리보기 칸)을 직접 검사하는 테스트는 같은 성질을 새 동작으로 검사하도록 고친다(설계자 판단). 예: IME 조합 중 Enter는 줄을 나누지 않는다, 느린 저장 중 ⌘Enter 뒤 입력은 새 블록에 들어간다, 원격 쓰기 뒤에도 같은 Quill 편집기와 내용이 유지된다.

## 4. 접근 방식
| 방식 | 내용 | 판단 |
|---|---|---|
| A. 지금 방식 + 단축키 | textarea에 기호를 넣고 블록 밖에서 렌더링한다. | 사용자가 B를 골랐다. |
| **B1. Quill 2 기반 WYSIWYG (선택)** | 블록을 누르면 그 블록에만 Quill 편집기를 붙인다. 저장할 때는 Markdown+작은 HTML로 바꾼다. | IME, 단축키, 목록 처리가 검증돼 있다. 커스텀 수식 블롯을 붙일 수 있고, cdnjs에 UMD(2.0.2)가 있다. |
| B2. contenteditable을 직접 구현 | | 한글 IME와 커서 처리를 처음부터 다뤄야 해서 버그 위험이 크다. |
| B3. ProseMirror/TipTap | | 쓸 만한 UMD 빌드가 없어서 CSP 안에서 불러오기 어렵다. |

사용자는 B(노션식)를 골랐고, 만드는 방식은 설계자에게 맡겼다. → **B1**.

## 5. 설계 (표시가 없는 항목은 설계자 판단)

### 5.1 편집 흐름
- 화면에 보이는 글 블록은 지금처럼 정적으로 렌더링한다. 블록을 누르면 그 블록에만 Quill이 붙는다. 한 번에 하나만 편집하고, 바깥을 누르거나 Esc를 누르면 저장한 뒤 정적 렌더링으로 돌아간다.
- **편집 중 모습과 정적 모습이 같도록** 두 경우 모두 같은 CSS 클래스(제목, 색, 크기, 형광펜, 목록, 체크박스)를 쓴다.
- Enter는 같은 블록 안의 새 줄이다. 목록에서는 다음 항목이 된다. **⌘Enter는 아래에 새 블록**을 만든다. 블록 밖 "＋ 글" 버튼도 그대로 둔다. (노션과 달리 블록이 여러 줄을 담는 이유: 목록과 제목이 한 묶음으로 저장되고, Claude가 쓰는 블록 모양과 맞추려는 것이다.)
- 빈 블록에서 Backspace를 누르면 블록을 지우고 이전 블록으로 이동한다(지금 동작 유지).
- 수식 블록(`type: "math"`, 캡처→LaTeX로 생긴 것)은 지금의 LaTeX 편집기와 실시간 미리보기를 그대로 쓴다.

### 5.2 꾸밈과 입력
- **단축키**:
  - ⌘B 굵게, ⌘I 기울임, ⌘U 밑줄, ⌘⇧S 취소선, ⌘E 인라인 코드
  - ⌘⇧H 형광펜(마지막에 쓴 색, 처음에는 노랑)
  - ⌘Enter 새 블록, Esc 편집 끝내기
- **Markdown식 자동 변환**(줄 맨 앞에서 입력하고 띄어쓰기):
  - `#`/`##`/`###` → 제목 1·2·3
  - `-`/`*` → 글머리 목록, `1.` → 번호 목록, `[]`/`[ ]` → 체크박스
  - `>` → 인용
- **인라인 수식**: `$...$`를 닫는 `$`를 치는 순간 수식으로 바뀐다(기존 `splitMath` 규칙 그대로라서 `$5–$10`은 그대로 글자다).
- **줄 단위 수식은 지금처럼 수식 블록(`type: "math"`) 하나로만 둔다**(설계자 판단: 두 곳에 나뉘면 메뉴, 내보내기, Claude 규칙이 복잡해진다). 빈 블록에서 `$$`를 치면 그 블록이 수식 블록이 된다(지금 동작 유지). 내용이 있는 블록의 빈 줄에서 `$$`를 치고 띄어쓰기하면, 그 줄을 지우고 **바로 아래에 새 수식 블록**을 만들어 LaTeX 입력을 연다.
- **수식 고치기**: 편집 중에 수식을 누르면 작은 팝오버가 열린다. 그 안에 LaTeX 입력칸과 실시간 미리보기가 있고, Enter로 반영, Esc로 취소한다.
- **선택 도구막대**: 편집 중에 글자를 고르면 위에 뜬다. 버튼은 다음과 같다.
  - `[B] [I] [U] [S] [코드] | [제목 ▾ 본문/1/2/3] [크기 ▾ 작게/보통/크게] | [글자색 ▾] [형광펜 ▾] | [∑ 수식으로]`
  - "수식으로"는 고른 글자를 인라인 수식으로 바꾼다.
- **색 팔레트**: 9색이다(기본, 회색, 갈색, 주황, 노랑, 초록, 파랑, 보라, 빨강). 글자색과 형광펜이 같은 이름을 쓰고, 라이트·다크 모드 값을 토큰으로 따로 둔다.
- **크기**: 작게(0.85em), 보통, 크게(1.25em) 세 단계다.

### 5.3 저장 형식 (블록 `text`)
- 기본은 Markdown이다: `#`, `**`, `*`, `~~`, `` ` ``, `- `, `1. `, `- [ ]`/`- [x]`, `> `, `$..$`, `$$..$$`.
- Markdown에 없는 꾸밈은 작은 HTML로 넣는다.
  - 밑줄: `<u>…</u>`
  - 글자색: `<span data-c="red">…</span>`
  - 형광펜: `<mark data-c="yellow">…</mark>`
  - 크기: `<span data-s="small|large">…</span>`
  - 허용하는 속성은 이 셋(`data-c`, `data-s`, 태그 `u`/`mark`/`span`)뿐이고, 렌더링 시 DOMPurify 허용 목록으로 제한한다.
- 변환기 두 개: `mdToDelta(text) → Quill Delta`, `deltaToMd(delta) → text`. 정상적인 입력에서는 **왕복해도 같은 결과**(`deltaToMd(mdToDelta(t))`)가 나와야 한다. 공백과 줄바꿈 정규화 정도의 차이만 허용한다.
- **어떤 블록을 Quill로 열지(설계자 판단: 엄격한 왕복 검사)**: 블록을 열기 전에 `deltaToMd(mdToDelta(text))`가 `normalize(text)`와 같은지 본다. `normalize`는 끝 공백과 연속 빈 줄 정리만 한다. 같으면 Quill로, 다르면 지금의 원문 textarea로 열고 "이 블록은 원문으로 편집돼요" 안내를 띄운다. 사용자가 손대지 않은 부분이 몰래 바뀌는 일이 없게 하려는 것이다(반목표).
  - Quill로 다루는 문법(정규형): 제목 `#`~`###`, `**굵게**`, `*기울임*`, `~~취소~~`, `` `코드` ``, `[글](url)` 링크, `- ` 글머리(한 단계 들여쓰기까지 2칸), `1. ` 번호, `- [ ]`/`- [x]`, `> ` 인용, `$..$`, 위 HTML 꾸밈, 문단 사이 빈 줄 하나.
  - 그 밖의 것(표, 코드 블록, 이미지, `$$` 줄 수식, `_x_`·`__x__`·`*`/`+` 글머리 같은 다른 표기, 문단 안 줄바꿈, 알 수 없는 HTML)은 원문 편집으로 간다.
  - SKILL §7에 Claude가 쓸 때 정규형을 쓰라고 적는다. 그러면 Claude 블록도 대부분 Quill로 열린다.
- **바꾸지 않았으면 저장하지 않는다**: 열었다 닫기만 하면 `text`를 다시 쓰지 않는다.

### 5.4 Claude와 내보내기
- SKILL §7에 꾸밈 문법을 추가한다(색, 형광펜, 밑줄, 크기 태그와 체크박스). Claude가 "중요한 건 형광펜"처럼 요청받으면 쓸 수 있다.
- Markdown 내보내기는 `text`를 그대로 쓴다. 노션 등 다른 곳으로 가져갈 때 HTML 꾸밈이 일부 사라질 수 있다는 점을 README에 적는다.

### 5.5 라이브러리
- Quill 2.0.2 `quill.js`(cdnjs, 버전 고정)를 쓴다. CSS는 `quill.core.css`에서 필요한 규칙만 골라 페이지에 넣는다. 테마(snow/bubble)는 쓰지 않고, 도구막대는 직접 만든다.
- 커스텀 블롯:
  - `MathInline`(Embed): 값은 LaTeX, MathJax SVG로 그린다.
  - 형식: `color`, `highlight`, `size`는 Parchment ClassAttributor나 data 속성으로 만든다. Quill 기본의 인라인 style 색은 쓰지 않는다. 팔레트와 다크 모드를 지키려는 것이다.

## 6. 설계자에게 맡기는 것
- 도구막대의 위치와 디자인, 키보드 접근성의 세부.
- 변환기 구현 방식(marked 토큰 → Delta, Delta → 문자열 직접 생성).
- 체크박스를 클릭했을 때 편집 상태가 아니어도 토글할지 여부(설계자 판단: 정적 상태에서도 클릭하면 토글하고 저장).

## 7. 위험
- Quill 2와 MathJax SVG 블롯을 같이 쓰는 부분(복사·붙여넣기, 커서 이동)은 만들어서 확인해야 한다.
- 왕복 변환에서 생기는 미묘한 차이(목록 들여쓰기, 줄바꿈)는 테스트로 고정한다.
